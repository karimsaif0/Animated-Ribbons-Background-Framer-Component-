## ✨ Overview

Animated Ribbons is a decorative Framer background component built around six handcrafted SVG ribbon paths.

Instead of relying on heavy particle systems, it uses lightweight SVG path rendering to create expressive, flowing compositions for hero sections, portfolios, creative studios, product pages, and experimental layouts.

Every ribbon can be positioned, rotated, scaled, recolored, and given its own three-color gradient.

The component supports On Load, In View, and Scroll-driven drawing animations, plus optional grain texture, staggered motion, reverse scroll animation, reduced-motion support, and static-renderer handling.

## 💡 Recommended Setup

For a hero section:

- Line Count: 6
- Stroke Width: 3
- Rounded: On
- Animation: On
- Trigger: In View
- Play Once: On
- Duration: 1.8s
- Stagger: 0.12s
- Grain: Optional

For a scroll-based hero, try Trigger: Scroll, Scroll Start: 0%, Scroll End: 100%, and Scroll Stagger: 10–20%.

## 🧩 Component Structure

The component is built as a self-contained Framer Code Component using SVG paths, inline SVG gradients, a responsive viewBox, CSS path-drawing animation, and requestAnimationFrame-based scroll progress.
